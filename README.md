# 🛸 PROZERRR — Localhost Project Hub & Dev Dock

> Ultra-minimalist, sleek local dev project dashboard & macOS/Raycast style dock bar for managing and launching all web projects on Laragon / Localhost.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/eazer123Z/prozerrr-hub)

---

## ✨ Features

- 🌌 **Obsidian Minimalist Aesthetic:** Deep-space dark canvas (`#07080a`), glassmorphic panels, and multi-layer inset shadows inspired by Raycast and Linear.
- ⚡ **Spotlight Command Search (`Ctrl+K` / `/`):** Instant fuzzy filtering by project name, tech stack tags, categories, or directory path.
- 🚀 **Prozerrr Core Suite Direct Jumps:** Press number keys `1` through `8` for instantaneous launching:
  1. **DeskTzy** — Desktop Widget & Overlay System
  2. **DownloadTzy** — Media & Video Downloader
  3. **GameTzy** — Game Launcher & Library
  4. **MusTzy** — Music Player & Audio Engine
  5. **RecTzy** — Screen Recorder & Capture Tool
  6. **SoundTzy** — Soundboard & Virtual Audio Routing
  7. **StreamTzy** — Cinema Streaming Portal
  8. **TweTzy** — Microblogging Social Feed
- 🛸 **Interactive macOS Floating Dock:** Bottom-docked launch bar with spring magnification, active status dots, tooltips, and quick action icons.
- 🛠️ **Localhost Environment Configurator:** Switch between:
  - Default Laragon path (`http://localhost/Prozerrr/[App]`)
  - Laragon Virtual Hosts (`http://[app].test`)
  - Custom base host / port (`http://127.0.0.1:8000`)
- 💻 **1-Click Open in VS Code:** Direct integration using Windows URI handler (`vscode://file/...`) to jump straight to your code editor.
- 📱 **Responsive & Adaptive:** Looks gorgeous on desktop 4K monitors and mobile viewports.
- 🌐 **Zero-Config Vercel Deployment:** Production static build ready to showcase online.

## 🚀 Getting Started

### Localhost (Laragon / Apache / Nginx)
Simply clone or place this repository inside your web server directory:
```bash
# Path: C:/laragon/www/prozerrr-hub
# Visit in your browser:
http://localhost/prozerrr-hub
```

### Deploy to Vercel
Deploy directly with 1 click using Vercel CLI or Git:
```bash
vercel deploy --prod
```

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + K` or `/` | Open Spotlight Search |
| `1` – `8` | Direct launch Prozerrr Suite app |
| `Esc` | Close modals / clear search |
| `?` | Show keyboard shortcuts modal |
| `Tab` / `Shift + Tab` | Navigate cards |
